ABout Dataset:
==============
Demand Forecasting Dataset

This dataset contains historical daily sales data for 10 stores and 50 different items over five years (2013–2017).

Dataset Features:
`date`: Date of the sales record.
`store`: Store identifier (1–10).
`item`: Item identifier (1–50).
`sales`: Number of units sold.

Dataset Size: 913,000 rows and 4 columns.

Objective: Explore historical sales patterns, analyse store-wise and item-wise performance, and practise data analysis and visualization using Python, Pandas, and Matplotlib.
