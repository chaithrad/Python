About Dataset:
==============
Students Performance Dataset

This dataset contains academic performance records of 1,000 students, including their demographic details, parental education, lunch type, test preparation status, and exam scores.

Dataset Features:
`gender`: Student gender.
`race/ethnicity`: Student group.
`parental level of education`: Parents' education level.
`lunch`: Lunch type.
`test preparation course`: Test preparation status.
`math score`: Mathematics marks.
`reading score`: Reading marks.
`writing score`: Writing marks.

Dataset Size: 1,000 rows and 8 columns.

Objective: Analyse student performance and explore relationships between demographic factors, test preparation, and academic scores using Python, Pandas, and Matplotlib.
